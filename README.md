# Nova Console

Игровая оболочка для Windows в консольном стиле: 4 раздела (Главная, Игры, Приложения, Сайты), управление DualSense, Steam-игры и пиратки, своя музыка, фон и логотип для каждой игры.

## Управление
| Действие | DualSense | Клавиатура |
|---|---|---|
| Двигаться | крестовина / левый стик | стрелки |
| Выбрать / играть | ✕ | Enter |
| Назад | ○ | Esc |
| Опции игры (изменить, убрать) | △ или Options | F2 |
| Разделы | L1 / R1 | PgUp / PgDn |
| Меню (питание, настройки, выход) | кнопка PS | F1 |
| Экранная клавиатура | ✕ на текстовом поле | — |

Файл или ярлык игры можно просто перетащить в окно.

## Как добавить игру
- **Steam:** плитка со стрелкой в разделе «Игры» → «Импорт из Steam». Найдёт установленные игры и сам скачает обложки, фоны и логотипы.
- **Пиратка или любая exe:** плитка «+» → «Обзор…» → выбери exe или ярлык. Название и иконка подставятся сами. Кнопка «Подтянуть оформление из Steam по названию» скачает красивые картинки. Если игра требует права администратора, включи переключатель. Если игра стартует через лаунчер, впиши имя её exe в поле «Процесс для учёта времени».
- **Свои оформление и музыка:** в окне игры можно выбрать иконку, фон, логотип и музыку, которая играет, когда игра выбрана в меню.
- Музыка для Главной, Приложений и Сайтов: Настройки (шестерёнка).

## Автозапуск и полный экран
По умолчанию оболочка запускается вместе с Windows на весь экран. Включается и выключается в настройках. Выйти в Windows: кнопка PS / F1 → «Выйти из оболочки». Для автовхода в Windows: Win+R → `netplwiz`.

## Встроенный браузер (Сайты)
Левый стик — курсор, правый стик и ↑↓ — прокрутка, ✕ — клик, ○ — назад, □ — экранная клавиатура, △ или кнопка PS — закрыть.

## Если DualSense не реагирует
Закрой Steam или отключи в нём «Поддержку конфигурации PlayStation», чтобы Steam не перехватывал контроллер. Подключай по USB или Bluetooth до запуска оболочки.

## Данные
Игры и настройки лежат в `data.json` и папке `assets` (в профиле пользователя или в `NovaData` рядом с portable exe). Для резервной копии скопируй эту папку (кнопка в настройках).
